プライバシーポリシー

最終更新日: 2026年10月25日

Daizu Personal Assistant（以下「本ツール」）は、作成者本人と家族のみが使う個人用ツールです。

取得する情報

利用者が Google アカウントで許可した範囲で、Gmail のメールとラベル、Google カレンダーの予定にアクセスします。

情報の保存と利用

  • 認証情報（トークン）は、利用者自身のパソコン内にのみ保存されます。
  • 取得した Google ユーザーデータは、利用者がその場で依頼した操作（検索、要約、下書き作成、予定の確認など）を行うためだけに使います。
  • 広告には使いません。第三者への販売、提供、共有は行いません。
  • 作成者を含め、人がこれらのデータを閲覧することはありません。

AI の利用について

利用者が依頼した内容を処理するため、該当するメールや予定の内容が、利用者が使っている AI サービス（Anthropic の Claude）に送られます。AI モデルの学習のために Google ユーザーデータを使うことはありません。

Google API サービスのユーザーデータポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

アクセス権の取り消し

利用者は、Google アカウントの権限設定から、いつでも本ツールのアクセスを取り消せます。

お問い合わせ

このページのリポジトリ（GitHub: mako-daizu/daizu-tool-pages）の Issues からご連絡ください。

English summary: This private tool accesses the user's own Gmail and Google Calendar only to perform actions the user requests. Tokens are stored on the user's own computer. Google user data is not sold, shared, used for advertising, or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
